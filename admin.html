Source strategyPreferred order for new dealers
1. Dealer feed / API

Best: structured XML/JSON/CSV supplied by the dealer. Stable IDs and image URLs are much more reliable than HTML scraping.

2. XML sitemap

Use the dealer's sitemap/index to discover canonical vehicle URLs, then read each authorized detail page for fields and images.

3. Authorized HTML sync

Follow pagination and individual vehicle links when a dealer authorizes website extraction. Keep source URLs attached to every vehicle.

4. Image rights

Only mirror/proxy dealer photos when your agreement covers image use. Otherwise show a link to the dealer listing or use a dealer-provided feed.
